# S13down — first public alpha

Open a Markdown file, read it, make a quick edit, and get on with your day. S13down is a small desktop app with ordinary files, no account and no document library. Editable source is one switch away.

This is an **alpha prerelease** for Windows and macOS. Please test with copies of your documents and [report problems](https://github.com/Studio13-NYC/S13down/issues).

## First launch and default app

- **Windows:** the installer can install WebView2 if needed. The binaries are unsigned, so Windows may show a reputation warning. To set the default, right-click an `.md` file → Open with → Choose another app → S13down → Always.
- **Mac:** the app has an ad-hoc signature but is **not Apple-notarized**. If first launch is blocked because the developer cannot be verified, follow [Apple's Open Anyway instructions](https://support.apple.com/en-us/102445) if you trust this build. Set the default through Finder → Get Info → Open with → S13down → Change All. Repeat separately for `.markdown` if needed.

## What is included

- Readable, editable documents on opening; Source mode for direct Markdown edits.
- Open, Save, Save As, undo across modes, draft recovery and external-change protection on Save.
- Windows Ctrl shortcuts; Mac Command shortcuts, native menus and Finder document opening.
- Separate document windows with independent save destinations and system light/dark appearance.

## Alpha limits

Interactive native Mac QA is still pending with Mac users. CI exercises the editor in Chromium/Edge and WebKit and tests Rust file handling; the Mac bundle is checked for both architectures and a valid ad-hoc signature. These checks do not replace testing Finder, native menus, installation and native dialogs on real Macs.

Documents must be UTF-8 and at most 10 MB. Rich edits can normalize Markdown formatting. Unsupported syntax falls back to Source. There are no tabs, library, export, math/diagrams or plugins. See the [README](https://github.com/Studio13-NYC/S13down/blob/v0.1.0-alpha.1/README.md) for file behavior and the [Mac QA checklist](https://github.com/Studio13-NYC/S13down/blob/v0.1.0-alpha.1/docs/MAC-QA.md) for testing.
